Santosh Singh Infra website

Files
- index.html : the whole website (open it in a browser to preview)
- App/sscompony.apk : the worker payment app (linked from the website; keep the App folder next to index.html)

Before publishing
1. Open index.html in a text editor and find the line: var WHATSAPP = '';
   Put your WhatsApp number between the quotes with country code and no + or spaces, for example '919876543210'.
   If it is left empty, worker applications open as an email instead.
2. Upload index.html and the App folder together to your hosting.
